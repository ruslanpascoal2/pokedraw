Como jogar
  1. Crie uma sala e mande o código (ou link) para os amigos.
  2. A cada rodada aparece a silhueta de um Pokémon da 1ª geração.
  3. Desenhe o Pokémon dentro do tempo.
  4. Todos votam no melhor desenho — a votação é cega, ninguém sabe de quem é cada desenho.
  5. O pódio mostra os vencedores da rodada e, no fim, o campeão geral.
